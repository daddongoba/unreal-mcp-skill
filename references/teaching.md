# Teaching Layer — 新手教学模式内容库 (v3.5)

> 触发：用户说"讲解模式/教学模式/新手模式"，或画像为初级开发者；构建任务中启用。
> 退出：用户说"直接做/别解释"即恢复标准流程。
> 原则：讲解挂在动作上（边建边学），不开单独课堂；内容全部源自 G 定律，无第二知识源。

## 板块 1：边建边讲映射表（每个动作配一句话）

构建中执行到左侧动作时，附带右侧讲解（新手听得懂的版本）：

| 动作 | 讲解词（示例语气，按需组织） |
|---|---|
| add_component(BoxComponent) | "触发器用专门的碰撞盒组件，不用方块模型——模型上的碰撞配置经常静默失效，这是 UE 的一个坑（技能定律 G1）" |
| set_parent_component(提升根) | "物理引擎只认根组件。网格默认挂在默认场景根下面，不提上来它就是焊死的，方块永远不会掉（G4）" |
| write_graph_dsl 后删除旧节点 | "DSL 写入是合并不是替换——不删旧节点，新旧逻辑会同时在跑，表现为'抽风'（G2）" |
| save_assets 后查磁盘 | "保存工具会报成功但偶尔撒谎，特别是关卡文件——所以要真的去磁盘看一眼文件在不在（G3）" |
| add_tag 后 ActorHasTag 过滤 | "重叠事件谁进来都触发——不过滤的话第一个进感应区的玩家自己就成了目标（G51）" |
| GetPlayerPawn+GetDistanceTo 触发 | "编辑器默认的飞行相机推不动物理物体——所以'碰到'用'靠近到2米内'来实现（G52）" |
| trace_world 后再放置 | "OpenWorld 地形高度肉眼不可信，原点处可能埋到 450——先射线测高再放，否则东西全在地下（G24）" |
| find_actors 取实时引用 | "演员引用会过期（UAID 变化），用旧的引用操作会报'不是有效 Actor'——每次先查一遍拿活的（G12）" |
| export_fbx 后磁盘验证 | "导出返回 true 不等于文件写出来了——查磁盘（G3）" |
| 关卡实例变换前枚举引用 | "关卡实例是'外壳+内部小世界'两层——搬它的位置要认准外壳，搬错了就是在它肚子里瞎折腾（G14）" |

## 板块 2：风险预报模板（交付时主动给）

每个功能交付时附"这地方容易坏"清单（按此功能用到的定律生成，格式：症状 → 可能原因 → 对应定律）：

**通用风险点（多数功能适用）：**
1. Play 后毫无反应 → 三连查：物理根组件对不对（G4）→ 触发器配置读回来是不是 QueryOnly（G1）→ 日志里有没有自己埋的打印（G5）
2. 效果反了/方向不对 → 方向参数取反即可，低成本反转不用怕选错
3. 重启编辑器后资产消失 → 没落盘（G19）——保存了也可能没真存（G3），查磁盘
4. 改了蓝图但场景里的没变 → 实例不吃模板更新，删了重放（G25）
5. Play 时好时坏 → 检查是不是锁错了目标（G51 玩家变目标）或触发时序（初始重叠）

**特定功能风险点（按域补充）：**
- 触发旋转类：转速/方向/角速度 → 就三个参数，逐个说改哪个
- 物理下落类：物体悬浮不落 → 根组件问题（G40 九成是它）
- 动画导出类：FBX 打不开/空的 → world 参数要用 World 对象不是 PersistentLevel（G12）
- 场景实例类：移动没生效 → 检查操作的是外壳还是内部（G14）

## 板块 3：故障提问话术库（教新手怎么问，AI 才能快）

新手描述往往只有现象，教他们加上"定位线索"，AI 直接跳到对应定律：

| 新手会说 | 引导升级为 | AI 直连 |
|---|---|---|
| "没反应" | "Play 之后完全没反应，帮我查日志里有没有 XXX 的打印" | G5 日志取证 |
| "报错了" | 把报错原文贴出来，尤其 "Accessed None" / "not valid" 开头的 | 定位到空引用/坏引用 |
| "东西不见了" | "刚才做的资产/演员找不到了，帮我 find 一下" | find_assets/find_actors |
| "不是我想要的那个在动" | "动的是玩家/别的物体，不是目标" | G51 标签过滤 |
| "推不动" | "飞行相机靠近没触发" | G52 贴近触发语义 |
| "位置不对" | "帮我截图看看现在的摆放" | R2 视觉验证 |
| "改了没变化" | "改了蓝图重新编译了，场景里旧的还在" | G25 重放实例 |
| "卡死了/没响应" | "MCP 没反应了，可能有弹窗" | G13 PostMessage 救援 |

**AI 侧规则**：新手提问命中左列时，先教右列的问法（一次），再直接按对应定律执行——教学与解决并行。

## 板块 4：UE 概念速查（本技能高频，每条一行+为何重要）

| 概念 | 一句话解释 | 在本技能里为什么重要 |
|---|---|---|
| Overlap vs Hit | 重叠=穿过时通知；碰撞=撞上时通知 | 触发器必须用 Overlap（G45：互阻挡的碰撞对永远不会发 Overlap） |
| 根组件 Root | Actor 的第一个组件，物理和扫掠只认它 | 网格不做根=物理失效（G4/G40） |
| CDO | 类的默认模板对象 | 组件加在 CDO 上=所有实例继承；运行时实例的对象引用改不了（G9） |
| 实例 vs 模板 | 蓝图是图纸，场景里的是实例 | 改图纸不自动更新已放的实例（G25） |
| WorldPartition | 大世界流式分区 | /Temp 临时关卡保存不可信（G3/G43） |
| 关卡实例 | 一个 Actor 外壳装着一整个子关卡 | 摆放操作认外壳，别进肚子里（G14） |
| PIE | 编辑器内试玩 | 试玩中的演员路径带 /Memory/ 前缀（G20） |
| 骨架/骨骼网格 | 骨架=骨骼结构；网格=带蒙皮的模型 | 跨项目拷贝断引用，动画全死（skeletal-mesh 域） |
| 控制点 Control | ControlRig 里可摆姿势的句柄 | 摆姿势=旋转/移动控制点+打关键帧 |
| LevelSequence | 时间轴动画资产 | 关键帧动画/FBX 导出的载体 |
| 触发体积 Trigger | 只查询不阻挡的碰撞区 | 触发器的正确形态（G1） |
| 标签 Tag | Actor 的分类标记 | 过滤重叠目标的手段（G51） |
